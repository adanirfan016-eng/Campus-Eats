# Campus Eats

A responsive university food-ordering website built with React, Vite and Tailwind CSS.

## Run locally

1. Install Node.js (LTS): https://nodejs.org/
2. Extract this ZIP.
3. Open the `Campus-Eats` folder in VS Code.
4. Open Terminal > New Terminal and run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
```

Vite creates the production website in `dist/`.

## Features

- Responsive desktop, tablet and mobile layouts
- Home, restaurant menu, food details, cart, checkout and confirmation
- Search, category filters, favourites and quantity controls
- Cart subtotal, campus service fee and total calculation
- Demo login/signup interface
- Demo order tracking
- Accessible labels, focus states and semantic page landmarks

## Note

This is a frontend academic prototype. Orders, login and payment methods are simulated in the browser; no real payment is processed and no backend database is connected.
